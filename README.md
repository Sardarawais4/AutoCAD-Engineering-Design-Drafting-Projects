Overview

This repository contains a collection of mechanical engineering design and technical drafting projects developed using AutoCAD. The projects cover 2D engineering drawings, mechanical components, machine elements, manufacturing drawings, casting and mould-related designs, and other engineering applications.

The work demonstrates practical skills in creating accurate engineering drawings, applying dimensions and annotations, developing sectional views, and preparing designs according to manufacturing and engineering requirements.

Project Purpose

The purpose of these projects is to develop practical skills in Computer-Aided Design (CAD) and mechanical engineering drafting, with a focus on designing components and preparing technical drawings suitable for manufacturing and engineering applications.

These projects demonstrate my practical experience in AutoCAD-based mechanical design, engineering drafting, and manufacturing-oriented drawing preparation.
